     6→     6→## Architecture decisions
     7→     7→
     8→     8→- **Only `/` page route exists** (sandbox constraint). The whole public site AND admin panel are client-side views inside `src/app/page.tsx`, driven by a hash router (`#/`, `#/products`, `#/product/[slug]`, `#/category/[slug]`, `#/blog`, `#/blog/[slug]`, `#/about`, `#/contact`, `#/faq`, `#/page/[slug]`, `#/search`, `#/thank-you`, `404`, `#/admin`).
     9→     9→- All backend logic lives in `src/app/api/**` route handlers (fetch-based, no server actions).
    10→    10→- SEO handled client-side: `src/lib/seo.ts` sets document title/meta/canonical/JSON-LD per view. Sitemap + robots served by API routes.
    11→    11→- Admin auth: scrypt password hashing (Node crypto, no deps) + session tokens in httpOnly cookie `abk_admin_session`.
    12→    12→- Leads stored in DB (`Lead` model) + optional Google Sheets webhook forwarding (setting `googleSheetsWebhookUrl`) server-side only.
    13→    13→- Images generated into `/public/images/` (brand set done by lead agent). Uploads go to `/public/uploads/`.

    31→    31→## API CONTRACT (envelope: { ok: true, data } | { ok: false, error })
    32→    32→
    33→    33→### Public
    34→    34→- GET `/api/public/bootstrap` → SiteSettings
    35→    35→- GET `/api/public/home` → HomeData { hero, brandIntro, featuredCategories, featuredProducts, whyChoose, customOrders, memoryPreservation, latestBlogs, faqs, finalCta } (sections are HomepageSection|null)
    36→    36→- GET `/api/public/categories` → PublicCategory[] (published, ordered by displayOrder; includes productCount)
    37→    37→- GET `/api/public/categories/[slug]` → { category, products: PublicProduct[], faqs: Faq[], relatedCategories: PublicCategory[], relatedBlogs: PublicBlogPost[] }
    38→    38→- GET `/api/public/products?page=1&pageSize=12&category=slug&q=search&featured=1` → Paginated<PublicProduct>
    39→    39→- GET `/api/public/products/[slug]` → { product, faqs, relatedProducts, relatedBlogs, category } (published only)
    40→    40→- GET `/api/public/blogs?page=1&pageSize=9&q=&tag=&cat=slug` → Paginated<PublicBlogPost> (status PUBLISHED, or SCHEDULED with publishAt<=now)
    41→    41→- GET `/api/public/blogs/[slug]` → { post, faqs, relatedProducts, relatedBlogs }
    42→    42→- GET `/api/public/blog-categories` → BlogCategory[]
    43→    43→- GET `/api/public/pages/[slug]` → PublicPage
    44→    44→- GET `/api/public/faqs` → Faq[] (entityType GENERAL, published)
    45→    45→- GET `/api/public/search?q=xyz` → SearchResults { products, categories, blogs, query }
    46→    46→- POST `/api/public/leads` body { name, mobile, city, product?, productUrl?, category?, message?, preferredContact?, sourcePage?, utmSource?, utmMedium?, utmCampaign?, referrer?, honeypot? } → { leadId, sheetSynced } (validates server-side, honeypot field `website` must be empty, rate-limited 5/10min per IP)
    47→    47→- GET `/api/sitemap` → XML sitemap (all published products/categories/blogs/pages)
    48→    48→- GET `/api/robots` → robots.txt text
    49→    49→
    50→    50→### Admin (all require session cookie; 401 JSON otherwise)
    51→    51→- POST `/api/admin/login` { email, password } → { user: {id,email,name,role} } + sets cookie
    52→    52→- POST `/api/admin/logout` → { success: true }
    53→    53→- GET `/api/admin/me` → { user } or 401
    54→    54→- GET `/api/admin/dashboard` → DashboardStats
    55→    55→- GET `/api/admin/products?page&pageSize&q&category&status` → Paginated<Product (full row + category name + images)>
    56→    56→- POST `/api/admin/products` body = full product fields (name required; slug auto if empty; images: [{url,alt,caption,isFeatured,displayOrder}]; highlights/customizationOptions are \n-separated strings) → { product }
    57→    57→- GET `/api/admin/products/[id]` → full product
    58→    58→- PUT `/api/admin/products/[id]` body same as POST → { product }
    59→    59→- DELETE `/api/admin/products/[id]` → { success: true }
    60→    60→- Same CRUD pattern for `/api/admin/categories`, `/api/admin/blogs` (+ fields: content HTML, status, publishAt ISO or "", blogCategoryId, relatedProductSlugs), `/api/admin/pages`, `/api/admin/faqs` (question, answer, entityType, entityId, displayOrder, published)
    61→    61→- GET `/api/admin/leads?page&pageSize&q&status` → Paginated<Lead>; PUT `/api/admin/leads/[id]` { status?, notes? } → { lead }; DELETE → { success }
    62→    62→- GET `/api/admin/media` → MediaAsset[]; POST `/api/admin/media` (FormData: file, alt?, caption?) → { media: MediaAsset, url } (saves to /public/uploads); PUT `/api/admin/media/[id]` { alt, caption, title }; DELETE `/api/admin/media/[id]` → also removes file
    63→    63→- GET `/api/admin/settings` → SiteSettings; PUT `/api/admin/settings` body = partial SiteSettings → { settings }
    64→    64→- GET `/api/admin/homepage` → HomepageSection[]; PUT `/api/admin/homepage/[sectionKey]` body = section fields → { section }
